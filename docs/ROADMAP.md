# Roadmap

## Completed in this prototype
- Manifest validation, deterministic planning and negative-path tests.
- Explicit boundaries around research candidates and unimplemented inference.

## Next experiment, not yet completed
1. Choose one lip-sync model and review exact code/weight/dependency licenses.
2. Create a local adapter with no automatic uploads and explicit output paths.
3. Run a consenting 15-second recording with original audio.
4. Compare identity, pronunciation, lip timing and visual artifacts.
5. Record hardware, versions, elapsed time, peak memory and retries.
6. Only then add optional speech synthesis and a local preview UI.

## Success criteria for an adapter
A reproducible command, reviewed licenses, explicit consent, measured resource use,
clear failure messages and a human-approved output. A passing manifest alone does
not meet these criteria.

No promised release date, production status, audience size or contribution history.
